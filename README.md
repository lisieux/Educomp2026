#Informações Gerais
Este repositório contém dados e resultados obtidos da pesquisa realizada sobre a acessibilidade aos materiais de estudo da OBI, por vezes o recurso anonymous.4open.science/ não apresenta todos os arquivos, para melhor visualizar, faça download deste repositório 

##Conteúdo
- Avaliações dos Itens de Prova (pré-teste e avaliações)
- Materiais utilizados (provas e tempo para avaliação)
- Resultados (classificação final dos itens de prova, relatórios de inspeção do site e pdf)
